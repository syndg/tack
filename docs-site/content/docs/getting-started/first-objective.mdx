title: First Objective
description: Submit your first objective and watch Tack work.
---

## Start the Daemon

```bash
tack daemon
```

The daemon is machine-wide and reads the user config layer. Open a new terminal for project-scoped CLI commands.

## Submit an Objective

```bash
tack plan "Refactor the auth module to use JWT"
```

Tack creates an objective for the current registered project and starts the run. Under the default `standard` blueprint, the planner explores the codebase and decomposes the objective into streams with file scopes and dependencies.

## Review the Plan

```bash
tack watch --summary
tack plans
tack show <plan-id>
```

The plan shows each stream's title, description, file scope, and dependency chain. Review it before approving.

## Approve

```bash
tack approve <plan-id>
```

Execution begins. Tack schedules streams based on dependencies and concurrency limits.

## Watch Progress

```bash
tack watch
tack watch --stream <stream-id>
tack watch --agent <agent-id>
```

Live stream of agent activity — tool calls, file edits, test results, and status changes.

```
18:16:12 [stream-1] builder: read src/schemas.ts
18:16:15 [stream-1] builder: edit src/routes/expenses.ts
18:16:19 [stream-2] builder: $ bunx tsc --noEmit
18:16:23 [stream-1] builder: done: Added PATCH endpoint
18:16:25 [stream-1] lint passed
18:47:35 [stream-1] merged ✓
```

## Check Results

```bash
tack status
tack merge --objective <objective-id>
tack merge diff <stream-id>
```

When all streams complete, Tack merges everything and creates a PR.

## Choose A Blueprint Explicitly

If you want a non-default workflow, pick a blueprint by `id`:

```bash
tack plan "Fix the typo in the README" --blueprint standard
```

Blueprint IDs are project-scoped and resolved from the current registry.
