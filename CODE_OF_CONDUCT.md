# Code of Conduct

Tack is an open-source project for building reliable agentic coding workflows. Keep the project useful, direct, and respectful.

## Expected Behavior

- Be kind, constructive, and precise.
- Assume good intent, especially in bug reports and reviews.
- Keep criticism focused on code, docs, behavior, and tradeoffs.
- Respect security boundaries and private information.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private credentials, logs, repository details, or vulnerability details without consent.
- Repeated low-effort noise after maintainers ask for clarification or scope.

## Enforcement

Maintainers may edit, hide, or remove comments and may block participants who make the project unsafe or unproductive.
