## Task 1.2: Create blueprint YAML loader

- Created `internal/harness/blueprint/loader.go` with `LoadFile`, `LoadDir`, and `Validate` per PRD spec.
- `LoadFile` reads YAML via `os.ReadFile` + `yaml.Unmarshal`, then calls `Validate` before returning.
- `LoadDir` iterates directory entries (non-recursive), loads `.yaml`/`.yml` files, skips non-blueprint files. Returns partial results with joined error if some files fail.
- `Validate` collects all errors (not just the first) and returns them joined with `;`. Checks: non-empty name, at least one step, unique step IDs, valid next references, type-specific requirements (agent→role, deterministic→action, blueprint_ref→ref), and unreachable step detection.
- Unreachable step detection: first step is always reachable (entry point), all other steps must be referenced by some step's `Next` field.
- Verified package compiles cleanly with `go build ./internal/harness/blueprint/`.
